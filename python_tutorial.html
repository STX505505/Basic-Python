Variables: Storing Data

name = "Ada"          # string (text)
age = 30             # int (whole number)
height = 1.72        # float (decimal)
is_student = True    # bool (True / False)

print("Hi, " + name + "!")
print("Next year you'll be", age + 1)

Rules

  • No declaration keyword — just variable = value
  • Names are case-sensitive: Name ≠ name
  • Use snake_case: user_name, total_price
  • Check any value's type with type(value)
print(type(age))   # <class 'int'>
print(type(height)) # <class 'float'>

Loops: Repeating Work

while — repeat while a condition holds

count = 3
while count > 0:
    print(f"Lift-off in {count}")
    count -= 1
print("Blastoff!")

Danger: forget to change count and it loops forever.

for — repeat over a sequence

for i in range(5):
    print(i)  # 0,1,2,3,4

for fruit in ["apple", "kiwi", "fig"]:
    print(f"I like {fruit}")
range(5) = 0..4. range(1, 6) = 1..5. range(0, 10, 2) = 0,2,4,6,8.

break and continue

for n in range(100):
    if n % 2 == 0:
        continue      # skip evens
    print(n)
    if n > 9:
        break          # exit the loop

Dictionaries & Sets

dict — key → value pairs

player = {
    "name": "Ada",
    "level": 7,
    "score": 950,
}
player["level"]           # 7
player["score"] += 50    # 1000
player["gold"] = 30      # new key
player.get("lives", 3)   # 3 (safe lookup)
for key, val in player.items():
    print(f"{key}: {val}")

set — unique items only

visited = {"home", "cafe", "home"}
# {'home', 'cafe'} — duplicates gone

all_items = {"apple", "bread"}
needed    = {"bread", "milk"}
all_items | needed   # union
all_items & needed   # intersection
Rule of thumb: ordered collection → list, key-value lookup → dict, unique items / membership tests → set.

Functions: Your Own Tools

def greet(name, excitement="!"):
    """Return a greeting."""
    return f"Hello, {name}{excitement}"

print(greet("Ada"))              # Hello, Ada!
print(greet("Bob", "????"))     # Hello, Bob????

Rules that make code "programmable"

  • DRY: do it once as a function, call it anywhere
  • Small functions, one job each, descriptive names
  • Default parameters make arguments optional
  • return gives a value back; print only displays

Returning multiple values

def circle(r):

Errors & Handling Exceptions

Errors you'll actually see

# NameError: 'nam' not defined
nam = "Ada"

# TypeError: 'int' + 'str'
x = 5 + "5"

# IndexError: list too short
[1, 2][5]

# ValueError: bad conversion
int("abc")

Handle them gracefully

age = None
while age is None:
    raw = input("Your age: ")
    try:
        age = int(raw)
    except ValueError:
        print("That's not a number, try again.")
print(f"You are {age}")

Pattern to remember

try:
    risky_work()
except SpecificError as e:
    print(f"Problem: {e}")
else:
    print("All good")     # only if no error
finally:
    cleanup()              # always runs

Reading & Writing Files

# Write
with open("notes.txt", "w") as f:
    f.write("First line\n")
    f.write("Second line\n")

# Read all
with open("notes.txt", "r") as f:
    content = f.read()

# Read line by line
with open("notes.txt", "r") as f:
    for line in f:
        print(line.strip())

Modern pathlib style

from pathlib import Path

path = Path("notes.txt")
path.write_text("hello\nworld")
lines = path.read_text().splitlines()
path.exists()   # True
Always use with: it guarantees the file is closed, even if an error happens mid-read. Modes: "r" read, "w" write (overwrites!), "a" append.

Classes: Bundling Data + Behavior

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            return "Amount must be positive"
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            return "Insufficient funds"
        self.balance -= amount

    def __str__(self):
        return f"{self.owner}: {self.balance:.2f}"

acc = BankAccount("Ada", 100)
acc.deposit(50)
acc.withdraw(30)
print(acc)   # Ada: 120.00

Concepts

  • Object = an instance of a class (like "Ada's account")
  • Attribute = data stored on the object (self.balance)
  • Method = a function attached to the class (deposit)
  • self = "this object"; it's passed automatically
  • __init__ runs when you create the object; __str__ defines print() output

Project: To-Do List Manager

Combines functions, lists, input, and error handling into a real tool.

def menu(tasks):
    while True:
        print("\n=== To-Do List ===")
        for i, t in enumerate(tasks, 1):
            mark = "x" if t[1] else " "
            print(f"{i}. [{mark}] {t[0]}")
        cmd = input("\nadd / done # / remove # / quit: ")
        if cmd == "quit":
            break
        elif cmd == "add":
            tasks.append([input("Task: "), False])
        elif cmd.startswith("done "):
            n = int(cmd.split(""))[1]) - 1
            tasks[n][1] = True
        elif cmd.startswith("remove "):
            n = int(cmd.split(""))[1]) - 1
            tasks.pop(n)

menu([])   # pass [] to start empty, or add sample tasks

Project: File Organizer

Automation is where Python earns its keep. This script sorts a folder by file extension.

from pathlib import Path

def organize(folder):
    folder = Path(folder)
    moved = 0
    for file in folder.iterdir():
        if file.is_file() and file.suffix:
            cat = file.suffix.lstrip(".").lower()
            dest_dir = folder / cat
            dest_dir.mkdir(exist_ok=True)
            file.rename(dest_dir / file.name)
            moved += 1
    print(f"Organized {moved} files.")

organize("./Downloads")

Result: Downloads/ → Downloads/pdf/, Downloads/png/, Downloads/zip/ ...

Run it as a daily scheduled task and your Downloads folder stays clean forever. This is "programmable" thinking: encode a routine once, execute it infinitely.

Mini-Project: Rock, Paper, Scissors

Uses random, functions, and a loop. Save as rps.py.

import random

moves = ["rock", "paper", "scissors"]

def winner(you, cpu):
    if you == cpu:
        return "Draw!"
    if (you, cpu) in {("rock", "scissors"), ("paper", "rock"), ("scissors", "paper")}:
        return "You win!"
    return "CPU wins!"

score_you, score_cpu = 0, 0
while True:
    you = input("Rock, paper, or scissors (q to quit)? ")
    if you == "q":
        break
    if you not in moves:
        continue
    cpu = random.choice(moves)
    result = winner(you, cpu)
    print(f"You: {you} | CPU: {cpu} → {result}")
    score_you += result == "You win!"
    score_cpu += result == "CPU wins!"
print(f"Final score: {score_you} - {score_cpu}")
Concepts practiced: tuple in set as a lookup table, += bool for score counting, input validation with continue.

Mini-Project: Error-Proof Calculator

A console calculator that never crashes on bad input. Save as calc.py.

def calc(a, op, b):
    if op == "+": return a + b
    if op == "-": return a - b
    if op == "*": return a * b
    if op == "/":
        if b == 0: raise ZeroDivisionError("Divide by zero!")
        return a / b

while True:
    raw = input("a op b (q to quit): ")
    if raw == "q":
        break
    try:
        a, op, b = raw.split()
        result = calc(float(a), op, float(b))
        print(f"= {result:.4g}")
    except (ValueError, ZeroDivisionError) as e:
        print(f"Invalid: {e}")

How it fits together

  • raw.split() parses "3 + 4" into three parts at once
  • One try block catches both bad numbers and divide-by-zero
  • The loop keeps running until the user quits
Challenge: add ^ for power and % for modulo — two new if lines in calc.

Mini-Project: Caesar Cipher

Classic encryption: shift every letter by a key. Great string-manipulation workout.

ALPHABET = "abcdefghijklmnopqrstuvwxyz"

def shift(letter, key):
    idx = ALPHABET.find(letter)
    return ALPHABET[(idx + key) % len(ALPHABET)]

def caesar(text, key):
    out = []
    for ch in text:
        lower = ch.lower()
        if lower in ALPHABET:
            shifted = shift(lower, key)
            if ch.isupper():
                shifted = shifted.upper()
            out.append(shifted)
        else:
            out.append(ch)   # keep spaces & punctuation
    return "".join(out)

print(caesar("Attack at dawn!", 3))  # Dwwdqn dw gdzq!
print(caesar("Dwwdqn dw gdzq!", -3)) # Attack at dawn!

Key trick: the modulo

(idx + key) % 26 wraps z + 3 back around to c. Negative keys work too, so the same function encrypts and decrypts.

Key idea: symmetric cipher

Encryption and decryption are the same operation with opposite keys. Real ciphers (Vigenère, substitution) build on exactly this pattern.

Mini-Project: Contact Book (with file save)

Dictionaries + JSON + exceptions = a real app whose data survives restarts.

import json
from pathlib import Path

DB = Path("contacts.json")

def load():
    if DB.exists():
        return json.loads(DB.read_text())
    return {}

def save(contacts):
    DB.write_text(json.dumps(contacts, indent=2))

contacts = load()
while True:
    print("\n1) add  2) find  3) list  4) quit")
    cmd = input("Choice: ")
    if cmd == "1":
        name = input("Name: ")
        phone = input("Phone: ")
        contacts[name.lower()] = phone
        save(contacts)
    elif cmd == "2":
        name = input("Find: ")
        print(contacts.get(name.lower(), "Not found"))
    elif cmd == "3":
        for n, p in contacts.items():
            print(f"  {n}: {p}")
    else:
        break
This is a full app: persistent data (json), a menu loop, safe lookups with dict.get. You can already build tools like this.
